# Dyna-SAuR

**Official repository for the paper *Dyna-SAuR*.**

This repository contains the code to reproduce results for **Dyna-SAuR**, **Infoprop**, **PPO-Lagrangian**, and **RL-DH** on the Walker and CartPole environments as reported in the paper.


## Dyna-SAuR Demo
Dyna-SAuR Demo video can be found in dynasaur.mp4 .

## Installation

**Prerequisites:** [Miniconda](https://docs.conda.io/en/latest/miniconda.html). If not installed:

```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh \
  && bash Miniconda3-latest-Linux-x86_64.sh \
  && rm -f Miniconda3-latest-Linux-x86_64.sh
```

**Create and activate the environment:**

```bash
conda env create -f environment.yaml
conda activate dynasaur_env
```

**Experiment tracking:**  
Experiments are tracked via [Weights & Biases (W&B)](https://wandb.ai). We recommend creating an account and following the [W&B quickstart guide](https://docs.wandb.ai/models/quickstart).

## Running Experiments

### Dyna-SAuR

**CartPole**

```bash
# Full method
python -m dynasaur.examples.main seed=1 experiment=DynasaurCartpole algorithm=dynasaur_cartpole

# Ablation: without filter action space
python -m dynasaur.examples.main seed=1 experiment=DynasaurCartpoleAblation1 algorithm=dynasaur_cartpole_old_param

# Ablation: without action regularization
python -m dynasaur.examples.main seed=1 experiment=DynasaurCartpoleAblation2 algorithm=dynasaur_cartpole_ablation_no_meta_loss

# Ablation: without starting state distribution shaping
python -m dynasaur.examples.main seed=1 experiment=DynasaurCartpoleAblation3 algorithm=dynasaur_cartpole_ablation_only_default_starting_states
```

**Walker**

```bash
# Full method
python -m dynasaur.examples.main seed=1 experiment=DynasaurWalker algorithm=dynasaur_walker

# Ablation: without filter action space
python -m dynasaur.examples.main seed=1 experiment=DynasaurWalkerAblation1 algorithm=dynasaur_walker_old_param

# Ablation: without action regularization
python -m dynasaur.examples.main seed=1 experiment=DynasaurWalkerAblation2 algorithm=dynasaur_walker_ablation_no_meta_loss

# Ablation: without starting state distribution shaping
python -m dynasaur.examples.main seed=1 experiment=DynasaurWalkerAblation3 algorithm=dynasaur_walker_ablation_only_default_starting_states
```

### Infoprop

Infoprop requires prior data generated by Dyna-SAuR. Follow these steps in order.

**Step 1.** Run the Dyna-SAuR CartPole and Walker experiments (see above).

**Step 2.** Set the replay buffer path in the Infoprop config files:

- `mbrl_lib_veh_cont/mbrl/examples/conf/overrides/info_cartpole.yaml`
- `mbrl_lib_veh_cont/mbrl/examples/conf/overrides/info_walker.yaml`

Set the field `load_replay_buffer_path:` to the absolute path of the folder where prior data was saved:

```
PathTillMainFolder/None/DynasaurCartpole/<date>/<expid>/
PathTillMainFolder/None/DynasaurWalker/<date>/<expid>/
```

**Step 3.** Navigate to the library directory and launch experiments:

```bash
cd mbrl_lib_veh_cont

# CartPole
python -m mbrl.examples.main overrides=info_cartpole dynamics_model=gaussian_mlp_ensemble experiment=Benchmark_Infoprop_CartPole_1 seed=1

# Walker
python -m mbrl.examples.main overrides=info_walker dynamics_model=gaussian_mlp_ensemble experiment=Benchmark_Infoprop_Walker_1 seed=1
```
